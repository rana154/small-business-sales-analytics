# Small Business Sales Analytics

## Project Overview
This project focuses on analysing sales data for a small business, such as a cafe or restaurant.

The goal is to understand business performance and help owners make better decisions using data.

## Business Questions
- What is the total revenue generated?
- Which products sell the most?
- Which product categories generate the highest revenue?
- Which months have the highest sales?
- What is the average order value?
- Which payment methods are most popular?

## Tools and Technologies
- SQL (MySQL)
- Python
- Pandas
- Data Visualisation
- Power BI (planned)

## Project Objectives
1. Organise raw sales data.
2. Clean and prepare the data.
3. Analyse sales performance.
4. Identify trends and patterns.
5. Generate actionable business insights.
